# Strategy Research

每项候选投资策略拥有一棵研究树。树以固定策略和基准组织研究维度，独立 Study 可被多项策略复用。研究人员和 Agent 通过仓库中的结构化文档维护地图。

- [地图契约与维护指南](MAP_CONTRACT.md)定义节点、关系、证据与新增 Study 的操作。
- [地图定义](map.json)和 [JSON Schema](schema.json)共同供 Online `/roadmap` 与 Static Demo `#/roadmap` 使用。
- [研究方法论](METHODOLOGY.md)提供可选的研究职责和证据审阅背景。

[Research](../../market_research/ARCHITECTURE.md)、[Statistics](../../market_statistics/ARCHITECTURE.md) 和 [Backtesting](../../market_backtesting/ARCHITECTURE.md) 保有各自结果与业务契约的所有权。
