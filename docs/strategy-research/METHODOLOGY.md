# Strategy Research 方法论

[入口](README.md) · [地图契约](MAP_CONTRACT.md)

| 概念 | 研究职责 |
| --- | --- |
| Strategy | 记录初始投资假设，形式化持仓、合约选择、换仓、交易与资本假设。 |
| Baseline | 冻结参考策略，固定回测身份、输入、窗口和重放条件，建立可复现基准。 |
| Evaluation | 评价收益、风险及资本效率，披露所采用的口径与限制。 |
| Attribution | 分解收益、风险暴露与资本需求，形成可检验的诊断。 |
| Hypothesis & Study | 声明可检验的假设，开展描述统计、关联分析、预测检验和证据验证。 |
| Optimization | 将证据转化为明确的候选规则和适用条件，记录候选生成依据。 |
| Validation | 在可比输入、窗口、成本与资本假设下与冻结基准对照，记录结果与局限并反馈。 |

这七类概念提供可选的研究方法背景，地图中的每棵树按实际策略问题组织。研究可以分叉、汇聚，也可以因验证失败或出现新解释而回到早期问题。前置依赖描述完成研究所需的输入，研究动机描述问题的来源。反馈保留已冻结基准的身份。重新设定基准时显式建立新的比较身份。

会计归因应能与实际持仓、交易及损益核算对账。统计归因估计在给定模型和样本下的风险暴露与关联。统计关联需要额外检验才能支持可推广的预测。预测证据要通过可执行规则、交易成本、流动性、风险和资本约束下的比较，才能支持交易增量。历史基差折价和回归 Alpha 本身不足以证明可实现利润。

研究计划、交付实现、证据验收与结论分别记录。已有程序、数据或示例可以支持复现或继续研究。接受一项结论需要有明确的适用范围、可识别的结果或报告、可追溯的输入与方法，以及验收记录。支持假设、否定假设和无定论都可以成为验收后的研究结果。
