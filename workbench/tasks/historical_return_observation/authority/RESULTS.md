# Research results packages

Each independent research results package contains `scope.json`, the single structured description of its expected research scope: schema version, natural-language objective, canonical subjects, inclusive windows, observation metric and version, parameters, horizons and units, calendar, anchor and lookback semantics, and analysis methods and parameters. Derive and check scope against the actual frozen workflow, never infer intent from results or conceal missing samples. The scope schema version describes this document only; it is not a Task, ResearchPlan or DataLake schema version.

Scope describes expected research, not an execution DTO, frozen workflow, BatchResult, Gate state or G5 authorization. Results record actual statistics and coverage. A Run records a particular execution and original evidence; multiple Runs may support one scope and one results package. Repeated execution does not automatically create duplicate packages. The results package is a curated view, not a replacement for immutable RunStore artifacts. Preserve original artifact IDs and hashes and distinguish edited repository reports from frozen original bytes.

Discover the current [four-index results](../results/2026_four_index_returns/README.md); its evidence index identifies Runs and original artifacts. Use [RunStore](../../../contracts/STORAGE.md) to read and verify them. Local RunStore and external caches are not distributed with this repository.
