# Strategy Research Map Presentation

The [Strategy Research Map contract](../../../../docs/strategy-research/MAP_CONTRACT.md) owns document semantics. Online and Static Demo use the same Vite module compiled from the repository definition. The build plugin watches the canonical map and schema without adding a filesystem serving root.

The feature projects one Strategy tree at a time. A shared Study appears once in each applicable tree, retaining its canonical ID and all relationships within that tree. The feature owns vertical layout, readable viewport framing, selection, keyboard interaction, node type colors and the Inspector. Workspace composition supplies navigation and hrefs. The map performs no product requests or execution.
