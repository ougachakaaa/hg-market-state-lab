# Strategy Research Map Presentation

The [Strategy Research Map contract](../../../../docs/strategy-research/MAP_CONTRACT.md) owns document semantics. Online and Static Demo use the same Vite module compiled from the repository definition. The build plugin watches the canonical map and schema without adding a filesystem serving root.

Workspace composition supplies the Strategy ID from the URL and provides link navigation. The feature projects one Strategy tree at a time. A shared Study appears once in each applicable tree, retaining its canonical ID and all relationships within that tree. The feature owns vertical layout, readable viewport framing, selection, keyboard interaction, node type colors and the Inspector. The map performs no product requests or execution.

The top-to-bottom layout reserves disjoint horizontal ranges for siblings, sized from their descendants. Parents center over their children. Sibling order follows the canonical edge order and empty branches take only their card width. The tree includes each node's primary visual relationship as defined by the Map contract. Remaining relationships use lighter dashed connectors and take no subtree width. Connectors use clear space between layers, and selecting a node highlights all incident relationships in the projection. Finding details retain evidence references from every canonical source Study. The viewport preserves readable initial text and supports pan and zoom for wider trees.
