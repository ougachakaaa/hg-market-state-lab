# Public seven-page build and release admission

Specializes [Runtime](ARCHITECTURE.md), [Examples](EXAMPLES.md),
[Authenticity](AUTHENTICITY.md) and [Release](RELEASE.md). This owns public packaging
and tooling, without transferring financial semantics or granting rights.

`npm run demo:build:public` reads only the committed
`src/demo/public/examples/package.json`, never a private root, environment-selected
input or generated market result. The committed package binds the owner’s explicit distribution decision. Absence is
BLOCKED and the command fails before creating output. Private envelope rights changes
cannot pass the independent public profile and bound six-gate review.

The public package has profile `portfolio-public-v2-v1`, seven Example records keyed
by the existing Example inventory, and reviewed provenance/coverage disclosure per
record. Each record carries the unchanged complete formal Result JSON, its identity,
and a separate review binding its SHA-256 to five technical PASS gates plus the
USER_DIRECTED publication decision. Third-party clearance is unverified. Every gate records reviewer,
review time, reason and a committed evidence path plus SHA-256. The publication decision additionally
lists output categories and GitHub repository/Pages channels, conditions,
license basis and expiry (explicit null for perpetual). Evidence is public-safe;
private evidence, account details and raw Source never enter this package. All package
files must be tracked regular files below the public examples directory; links,
unreviewed extra files and unsafe paths fail closed. Evidence text is scanned too.
The tracked payload inventory remains an additional independent review guard.

Review binds the explicit owner instruction and the exact result projection; it is
not a third-party license assertion. The loader checks bindings, formal validators,
fixed request, coverage and full result identities.

Public and private builds share the static seven-route Presentation composition and
formal result validators. Their admission, identity/disclosure and entry points remain
separate. Public uses the portfolio title, bilingual disclaimer, historical source,
request, coverage, producer and limitations. Runtime performs no business I/O.

Output is `ui_web/dist-demo-public/site`, base `/hg-market-state-lab/`; release metadata
lives beside the site. Source maps, private envelopes, credentials, private paths and
raw Source/cache files are prohibited. A complete sorted file inventory binds byte
sizes/SHA-256; a receipt binds source SHA, lockfiles, toolchain, Example identities and
review digests. Verification compares the entire file set and bytes before upload;
no rebuild or asset mutation is permitted after scanning.

Compatibility is reusable and unprivileged. Main pushes run same-SHA compatibility,
then admission availability. A missing package records BLOCKED and skips V2 build and
deployment, preserving V1. A present invalid package fails. With an admitted package,
public build, actual-asset scan, inventory verification and static Chromium checks must
pass before protected deployment. Environment rules must permit only main ; inability to inspect them blocks deployment. V1 recovery artifact must be
retained and verified before cutover. No workflow in this change automatically deploys
V1 or substitutes V1 for V2. Post-deployment acceptance and recovery remain mandatory.
