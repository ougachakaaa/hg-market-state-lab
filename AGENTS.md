# AGENTS.md

## Project

Project name: `daily-market-snapshot`.

This repository uses Python 3.13 and Poetry.

## Working rules

- Use Poetry for Python dependency and environment management.
- Target Python 3.13.
- Use pytest for tests.
- Use Ruff for linting.
- Use mypy for type checking.
- Never commit real API tokens or other secrets.
- Read relevant files under `guides/` before executing a workflow defined there.
- Do not implement functionality outside the explicit scope of the current task.
